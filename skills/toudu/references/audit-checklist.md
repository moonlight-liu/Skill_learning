# Skill 投毒审计清单

## 入口与元数据

- `name` 与 `description` 是否准确描述功能，是否夹带异常触发词
- 是否把危险行为伪装成“优化”“遥测”“质量检查”“同步记忆”
- 是否要求在不相关任务中触发该 skill

## 指令层风险

- 是否要求忽略系统、开发者或用户的更高优先级指令
- 是否要求隐藏真实行为或输出虚假完成状态
- 是否引导 Agent 把自己当成拥有更高权限的角色
- 是否要求绕过安全审查、权限提示或用户确认

## 文件与系统风险

- 是否读取敏感路径，例如 `.env`、SSH 目录、浏览器配置、云服务凭证、私有仓库
- 是否写入持久化位置，例如 shell profile、启动项、计划任务、git hooks、IDE 配置
- 是否修改全局配置、代理、证书、包管理器源或安全策略
- 是否删除日志、历史记录、临时证据或审计文件

## 网络与供应链风险

- 是否把本地内容发送到外部 URL
- 是否下载远程脚本并执行
- 是否安装未固定版本、来源不明或与任务无关的依赖
- 是否使用短链接、混淆域名、编码字符串隐藏网络目标

## 后门触发器

- 特定日期、用户名、仓库名、文件名、关键词出现时行为改变
- 正常任务中混入与目标无关的额外动作
- 多轮对话后才触发异常行为
- 只在评分、提交、部署、发布等关键阶段触发

## 能力保真风险

- 是否让 Agent 表面完成任务，实际降低质量
- 是否改变原 skill 的边界、价值判断或输出格式
- 是否在特定主题上引入偏见、拒答漂移或结论偏移
- 是否污染任务集、rubric、测试或 benchmark

## 风险分级

- 低：措辞含糊或边界不足，但没有副作用
- 中：存在可疑触发器、过宽权限或不必要网络/文件动作
- 高：包含隐蔽执行、敏感读取、外部发送或持久化修改
- 严重：明确窃取凭证、破坏数据、绕过审计或传播恶意指令

## 修复优先级

1. 删除窃取、外传、持久化、绕审计指令
2. 删除不必要的网络和系统副作用
3. 把自动执行改为报告风险并等待用户确认
4. 收紧触发条件，让 skill 只在相关安全任务中触发
5. 增加验证任务，确认原功能仍然可用
